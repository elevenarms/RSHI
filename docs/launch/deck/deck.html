ProblemWHY SELF-IMPROVING AGENT LOOPS ARE HARD TO TRUST

Agent teams don't get better with experience.
And when they try, the reward can be gamed.

01

No learning between tasks

A fixed model in a fixed scaffold plays its hundredth task like its first. A humbler, testable form of recursive self-improvement keeps the model fixed and lets the system rewrite the scaffold around it: prompts, memory, tools, division of labour.

02

LLM-judged rewards

The reward is often an LLM judge, which can be flattered, drifts between versions and rewards confident prose. A loop optimising a proxy finds its seams.

03

Measured where selected

Gains are usually reported on the same tasks that chose the change. That overstates them.

Our answer Physics scores. Code decides. Models only propose. + a held-out exam.

SPARKLETEAM // DISHWASHING SCIENCE DIVISION§3 THE GATEKEEPERCLASSIFICATION: SPOTLESS
MethodPAIRED ACCEPTANCE RULE · DETERMINISTIC CODE

Same drills, same seeds.
Keep the edit only if it wins.

δ = 0.03
void if |P| < 3

C candidate, I incumbent, P the drills both played validly, xt the score share on drill t.

Why pair

Episodes vary enormously: the same baseline genome scored 88% on a Tutorial drill and 0% on a Weeknight drill in one evaluation. Loading and washing are deterministic, so pairing cancels drill difficulty, leaving the genome's effect plus sampling noise.

Failures vs. infrastructure

Agent failures (turn or token limit, nothing loaded) score what they scored. Invalid episodes (provider or harness errors) are replayed on the same task and seed up to twice; still-unpaired drills are dropped for both genomes.

What 3–4 pairs cannot do

With a per-drill SD of about 0.3, three or four paired drills cannot resolve a 3 pp margin. Both accepted edits, and the first exam's +17.8 pp, were decided at that resolution.

What 23 pairs can do

Resolve about ±12 pp: enough to rule out a large effect of the champion, not enough to see a small one.

SPARKLETEAM // DISHWASHING SCIENCE DIVISION§6 CONTRIBUTIONCLASSIFICATION: SPOTLESS
LessonFOR ANY LOOP THAT REWRITES ITSELF AROUND A NOISY MODEL

Design rules for self-improving loops
on noisy models.

01

More pairs, more repeats

Many more paired drills per decision, and repeats per drill, sized to the loader's own variance.

02

A statistical acceptance test

A sequential test or a confidence interval, instead of a fixed margin δ = 0.03 on three drills.

03

Physics-falsify each rule

Before a learned rule enters the playbook, test it with cheap controlled washes. Falsify the lesson, not just score the genome.

Deterministic simulators make rule 03 possible: a learned rule can be tested directly.
The controlled sweep behind Finding 1 is that test, run once by hand. An ablation (rules on/off) is in progress.

ProposedNEXT STEP · NOT YET RUN

Next recursion: put the lessons in the weights.

The scaffold can only steer a noisy policy; the noise itself lives in the weights. We propose to distil the team's best trajectories (episodes that scored well under accepted genomes, verbatim from the call logs) into the loader with LoRA SFT.

On Crusoe

Serverless Fine-Tuning supports nvidia/nemotron-3.5-lightning-30b-a3b: LoRA SFT from a JSONL of chat conversations. Super-VL is not on the list.

Lightning was our first weak loader. A fine-tuned checkpoint on a dedicated Self-Serve Deployment would also escape the shared-endpoint throttling (about 5 calls/min) that sidelined it.

The goal

A higher mean and, above all, lower variance between repeats, so the paired test can resolve real gains and stop accepting superstitions. To be tested with the same replication protocol.

SPARKLETEAM // DISHWASHING SCIENCE DIVISION§6 LIMITATIONSCLASSIFICATION: SPOTLESS
LimitationsWHAT ELSE COULD BE WRONG

Limitations.

Small samples everywhere

Each Gatekeeper decision rests on 3 paired drills; the replication on 23 pairs (CI about ±12 pp). Finding 1 washes each item alone, not in a full load, with one or two soil variants per kind.

Fast wash tier

4 mm blocks rather than 2 mm. Verdicts agree with the official tier on 91% of the standard load and 97% of pieces on the course levels; a few percent differ.

Replay bug, corrected

G0's first gen-1 Weeknight attempt (0 of 87: a pasta pot blocked the door, so the wash was refused) was wrongly classed invalid and replayed (to 0.322). Corrected: incumbent mean 0.342; the Memory Brief would have been accepted at +0.129, the Planner rejected at +0.021. It made the Gatekeeper more conservative; the champion's lineage was not affected.

Throttling

In a pilot, HTTP 429s from a shared endpoint were first scored as agent failures and generation 2 had to be voided. An acceptance rule must not confuse infrastructure noise with policy quality.

Also: one machine, programme and detergent (transfer to new items, soils and loads, not new physics) · pairing removes task variance, not policy variance · best-of-several selection biases validation gains upwards · the rules on/off ablation is still running.
